API ключи

Ключи — для внешних приложений. Сам сайт в ключе не нуждается.

Секрет администратора

Документация API

Базовый адрес: http://localhost:3000. Все ответы — JSON, кодировка UTF-8.

Авторизация

  • Сайт работает без ключа.
  • Внешние приложения шлют ключ заголовком X-API-Key: sk-... — по нему считается использование.
  • Ключ создаётся в «API ключи» (нужен секрет администратора, задаётся переменной окружения ADMIN_SECRET).

GET /api/models

Список моделей с формами: inputs (image / audio / video / text, «?» — необязательно), params (select / number / text / textarea / checkbox), tabs — вкладки.

curl http://localhost:3000/api/models
curl -H "X-API-Key: sk-..." http://localhost:3000/api/models

POST /api/generate

multipart/form-data:

  • model — id модели (из /api/models), напр. seedance
  • tab_id — id вкладки, если у модели есть вкладки (напр. talk / wait)
  • params — JSON со всеми параметрами формы: {"duration":5,"ratio":"16:9","seed":1234}
  • text — промпт, если модель его просит
  • image / audio / video — файлы; фото-референс обязателен там, где это указано в модели, без него вернётся 400

Ответ: {"task_id":"uuid"}. Ошибка: {"error":"..."}.

curl -X POST http://localhost:3000/api/generate ^
  -H "X-API-Key: sk-..." ^
  -F "model=seedance" ^
  -F "params={"duration":5,"ratio":"16:9","resolution":"720p","seed":1234}" ^
  -F "text=кот гуляет по городу" ^
  -F "image=@ref.jpg"

GET /api/task/{id}

Статус задачи: queued → running → completed / failed. Опрос раз в 3 секунды, генерация занимает до 25 минут.

curl -H "X-API-Key: sk-..." http://localhost:3000/api/task/uuid

{"status":"completed","result":{"url":"https://.../out.mp4","type":"video"}}
{"status":"failed","error":"описание ошибки"}

result.type: video / image / audio / voice_id (тогда в voiceId — id голоса).

Управление ключами (только админ)

POST   /api/keys            x-admin-secret + {"name":"имя"}
GET    /api/keys            x-admin-secret
DELETE /api/keys/{key}      x-admin-secret
