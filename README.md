# AIGC Генератор

Сайт-генератор поверх https://aigc.medicalai.tech/ со своей системой API-ключей.
Все модели, формы (промпт, длительность, референс и т.д.) берутся прямо с апстрима.
Бекенд сам заходит на сайт через headless-браузер, выбирает модель, заполняет
все поля пользователя, генерирует и отдаёт результат.

## Запуск

```bash
npm install
npx playwright install chromium
ADMIN_SECRET=свой-секрет npm start
```

Открыть http://localhost:3000

## API-ключи

Сайт работает **без ключа** — ключи только для внешних приложений.
В шапке сайта есть «API ключи» (создание/список/отзыв, нужен секрет
администратора) и «Документация» с примерами запросов.

Ключ шлётся внешним приложением заголовком `X-API-Key` — по нему считается
исключение. Если ключа нет — запрос тоже работает (для сайта), неверный ключ — 401.

Создать ключ curl'ом:

- `GET /api/models` — список моделей и их формы
- `POST /api/generate` — multipart: `model`, `tab_id`, `params` (JSON), `text`, файлы `image` / `audio` / `video`
- `GET /api/task/{id}` — статус задачи: queued → running → completed / failed

Фото-референс обязателен везде, где это указано в конфиге модели — бекенд
проверяет и без него не пустит.

## Как работает

1. Фронт тянет конфиг с апстрима и рисует форму под каждую модель (16 моделей,
   вкладки, промпты, длительность, разрешение, сид и т.д.).
2. Пользователь жмёт «Сгенерировать» — задача встаёт в очередь (по одной, т.к.
   апстрим не любит параллель).
3. Playwright открывает апстрим, дёргает его же `selectModule` / `switchTab`,
   подставляет файлы, текст и параметры, жмёт «开始生成».
4. Ждёт, пока сайт сам покажет панель результата (до 25 мин), забирает ссылку
   на видео/аудио/картинку или voice_id и отдаёт фронту.

## Файлы

- `server.js` — express, ключи, очередь, валидация обязательных входов
- `automation.js` — драйвер Playwright по апстриму
- `public/index.html` — весь фронт
- `keys.json` — создаётся автоматически, хранит ключи и статистику
